# Use Apache Kafka for Inter-Service Communication

## Status: Active

## Date: 2026-01-28

## Owner: Jhon

## Context: Direct REST calls between services created tight coupling and cascading failures when one service went down.

## Decision: Implement Apache Kafka as an event backbone for asynchronous communication (e.g., OrderPlaced events).
