- Ghost stock: show stock as available when it is actually missing, lost, or stuck in transit.

- API Gateway: A server or software component that acts as a single entry point for all client requests, managing traffic, authentication, and rate limiting.

- Asynchronous Communication: A method of data exchange where the sender does not wait for an immediate response from the receiver, improving decoupling and fault tolerance.

- C4 Model: A lean graphical notation technique for modeling software architectures across four levels: Context, Containers, Components, and Code.

- Database-per-Service: An architectural pattern where each microservice manages its own private data store, preventing schema dependencies and coupling between services.

- EC2 (Elastic Compute Cloud) An Amazon Web Services (AWS) utility providing resizable, static virtual servers (compute capacity) in the cloud.

- EKS (Elastic Kubernetes Service) A managed AWS service used to run, scale, and orchestrate containerized applications using Kubernetes.

- Event Broker: A middleware component (like Apache Kafka) optimized for receiving, storing, and distributing high volumes of asynchronous events or messages.

- Event-Driven: Architecture A software architecture pattern where microservices communicate via decoupled, asynchronous events triggered by state changes.

- Eventual Consistency: A consistency model used in distributed systems where data across replicated or separate stores becomes identical over time, rather than instantly.

- Istio: An open-source service mesh layer that provides secure, configurable, and observable communication between microservices networks.

- Monolith: A traditional software application model where all functional components (UI, business logic, data access) are tightly integrated into a single deployable unit.

- Polyglot Persistence: The practice of using different database technologies (e.g., Relational, NoSQL, Key-Value) within a single project depending on the specific data needs of each service.

- Redis: An open-source, in-memory data structure store used primarily as a high-performance database, cache, and message broker.

- Service Mesh: A dedicated infrastructure layer built directly into an app to handle secure service-to-service communication, load balancing, and encryption
