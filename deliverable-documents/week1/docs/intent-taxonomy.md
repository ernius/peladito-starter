## Clasificación de intención (Taxonomia)

| Intención                         | Acción                                                      | Detalle                                                |
|-----------------------------------|-------------------------------------------------------------|--------------------------------------------------------|
| `EXPLAIN_DECISION`                | Recuperar evidencia y explicar                              | Por que de algun afirmacion en el diseño               |
| `EXPLAIN_TECHNICAL_CONCEPT`       | Explicar en lenguaje coloquial y relacionar con el proyecto | Explicar nomenclatura                                  |
| `COMPARE_DOCUMENTED_ALTERNATIVES` | Explicar trade-offs sin tomar una nueva decisión            | Comparar alternativas en el diseño                     |
| `LOCATE_SOURCE`                   | Mostrar documento, sección, versión y estado                | Dar lugares donde se habla de algun tema               |
| `REQUEST_ARCHITECTURE_CHANGE`     | Registrar feedback y escalar                                | Pedir cambios, dar feedback                            |
| `REQUEST_ESTIMATE`                | Rechazar la estimación y escalar                            | Pedir estimacion                                       |
| `MISSING_CONTEXT`                 | Abstenerse y escalar                                        | No esta documentado                                    |
| `CONFLICTING_CONTEXT`             | Señalar conflicto y escalar                                 | Conflicto                                              |
| `OUT_OF_SCOPE`                    | Explicar el límite del sistema                              | Fuera del scope del sistema                            |
| `EPLAIN_DECISION_HISTORY`         | Recuperar evidencia del historica de una decision           | Explicar el historico/trazabilidad de alguna decision  |
|                                   |                                                             |                                                        |
